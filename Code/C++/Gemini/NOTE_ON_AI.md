# Note on the useage of generative AI
Some generative AI was used on the project, this was almost exclucivly used for things I simply didnt care about for this project, such as image parsing, repetative code changes, some help with finding and using python libraries and some minor code cleanup.

Besides that it was also of help with explaining concepts I didnt quite understand in papers to me. And explanation of some mathmatical notation.

For me personally the same rule always applies, Ai is a tool and if used, should be used as such. That, and **never push any code to production you dont completely understand**.
